# APIHub для кодинг-агентов

Подключайте установленные кодинг-агенты к APIHub одним ключом. Выберите приложение в меню, и настройщик запустит его через APIHub Auto. Рабочий каталог сохраняется. [Together Link](https://www.together.ai/link)

| Харнес | Как подключается |
| --- | --- |
| OpenCode | Сеансовый OpenAI-совместимый провайдер и модель APIHub Auto |
| DeepSeek Harness | Web UI с временным `--patch` и провайдером OpenAI Chat Completions |
| Kimi Code | Временная модель через `KIMI_MODEL_*` в актуальном Kimi Code CLI, стратегия `optimal` |
| Pi | Сеансовое расширение с провайдером APIHub Auto |
| Claude Code | Временный каталог настроек Anthropic Messages |
| Claude Desktop | Отдельный профиль APIHub Auto с запуском приложения на macOS |
| Codex CLI | Сеансовый провайдер OpenAI Responses и модель APIHub Auto |
| Continue CLI | Временный `config.yaml` для команды `cn` |
| Aider | Временные настройки модели и шлюза OpenAI Chat Completions |
| Cline | Инструкция подключения через OpenAI Compatible в настройках Cline |
| Cursor | Инструкция подключения своей чат-модели в настройках Cursor |
| ChatGPT Desktop | Штатный список моделей Codex |
| Antigravity | Подключение APIHub пока недоступно. [Поддерживаемые способы авторизации](https://antigravity.google/docs/install?tab=cli) |

## Быстрый старт

1. [Зарегистрируйтесь в APIHub](https://hub.gnzs.pro/register?utm_source=github&utm_medium=readme&utm_campaign=apihub-auto-setup). Первые запросы можно оплатить стартовым бонусом, который APIHub начисляет при регистрации.
2. [Создайте и скопируйте токен](https://hub.gnzs.pro/app/keys?utm_source=github&utm_medium=readme&utm_campaign=apihub-auto-setup).
3. Запустите команду ниже. Меню показывает поддерживаемых агентов и подсказывает, как установить отсутствующие. Ключ APIHub запрашивается при первом запуске и сохраняется локально с правами владельца.

Выберите «Настроить» → нужного агента → «Настроить и запустить». При первом запуске можно сразу продолжить с APIHub Auto или открыть каталог моделей. В «Настройках» можно выбрать режим «Сбалансированный», «Дешёвый», «Быстрый» или «Стабильный». Сбалансированный режим выбран по умолчанию. Стрелки перемещают курсор, Enter подтверждает выбор, цифра выбирает пронумерованный пункт. Esc возвращает на предыдущий экран, Q закрывает меню.

Можно попросить об этом агента, в котором вы уже работаете. Отправьте ему ссылку на этот README и сообщение.

Команда для macOS, Linux и Windows (x64). Нужен Node.js 22.19 или новее.

```sh
npx apihub-auto-setup
```

## Дополнительные модели

Выберите одноимённый пункт главного меню и введите часть названия или ID, например `deep` или `glm`. Стрелки перемещают курсор, пробел ставит или снимает отметку, Enter сохраняет выбор, Esc возвращает назад.

APIHub Auto остаётся моделью по умолчанию. Список применяется при каждом новом запуске из настройщика. В Claude Code модели видны в `/model` начиная с версии 2.1.242. Claude Desktop показывает выбранные модели, доступные через `/messages`, под их названиями в каталоге APIHub. Для Cline и Cursor настройщик выводит ID выбранных моделей в инструкции подключения. Kimi Code сохраняет настройки и сессии для запуска с дополнительными моделями в отдельном профиле APIHub.

## Помощник APIHub

Выберите «Помощник APIHub» и спросите, где подключить MCP, настроить агента, выставить API или посмотреть расходы. Настройщик покажет ссылки на нужные разделы кабинета. Вопрос обрабатывается локально и не расходует баланс.

## Claude Desktop

На macOS пункт «Настроить» → «Claude Desktop» создаёт или обновляет отдельный профиль «APIHub Auto», выбирает его и открывает Claude. При изменении профиля открытое приложение штатно перезапускается. Выберите «APIHub Auto» в списке моделей. Профиль обращается к шлюзу напрямую по HTTPS.

Для установки на другой системе или ручного импорта задайте `APIHUB_DESKTOP_PROFILE` — путь к новому JSON-файлу. В Claude Desktop включите Help → Troubleshooting → Enable Developer Mode. Откройте Developer → Configure Third-Party Inference → Import configuration, выберите этот JSON, примените профиль и полностью перезапустите приложение.

Терминальные агенты используют параметры текущего запуска. Для запуска без меню задайте `APIHUB_AGENT` равным `opencode`, `deepseek-harness`, `kimi-code`, `pi`, `claude-code`, `codex`, `continue`, `aider` или `claude-desktop`.

Чтобы вернуть настройки, выберите «Настроить» → нужного агента → «Восстановить настройки». В Claude Desktop восстановится прежний профиль. Для Claude Code, OpenCode и Codex настройщик предложит сохранённую резервную копию, если она есть. У сеансовых подключений настройки действуют до закрытия агента.

Ключ хранится в `~/.config/apihub-auto/credentials.json` с правами `0600`. Выбранные стратегии хранятся в отдельном файле каждого агента в каталоге `harnesses` рядом с ключом. Для смены ключа выберите «Сменить ключ APIHub» в главном меню. Путь к файлу ключа можно изменить через `APIHUB_KEY_FILE`.
